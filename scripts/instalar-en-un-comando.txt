================================================================
 SHAKEAHOLIC - dejar una PC lista
================================================================

 OPCION A (la facil): el archivo instalar-todo.bat
 -------------------------------------------------
 Doble clic. Windows pide permiso una vez, acepta, y ya:
 instala el agente de impresion, deja el arranque automatico
 y abre todo. No hace falta clic derecho ni PowerShell.

 Solo pide la llave publica de Supabase la primera vez.


 OPCION B: si no se puede pasar el archivo a esa PC
 --------------------------------------------------
 1. Tecla Windows -> escribir:  powershell
 2. Clic DERECHO -> "Ejecutar como administrador"
 3. Pegar esta linea y Enter:

----------------------------------------------------------------
Set-ExecutionPolicy Bypass -Scope Process -Force; [Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12; Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/EleevateMX/ventashake/main/scripts/instalar-todo.bat' -OutFile "$env:TEMP\shake.bat"; Start-Process "$env:TEMP\shake.bat" -Verb RunAs
----------------------------------------------------------------


 DESPUES DE ESTO
 ---------------
 * Al prender la PC se abre todo solo.
 * El agente se actualiza solo cuando haya version nueva.
 * Cambios de precios o productos: boton "Actualizar pantallas"
   en Admin - En vivo. NO hay que tocar esa computadora.
